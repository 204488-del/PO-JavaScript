# PO-JavaScript
Selina Aydin & Dea-Tsvetelina Ivanova


**Beschrijving van het programma:**

Wij hebben een website bedacht waardoor het makkelijker en leuker wordt om een outfit te kiezen. Op deze website kun je van je eigen kledingstukken, schoenen, tassen en andere accessoires foto's uploaden. Hierbij kun je verschillende kenmerken toevoegen, zoals de kleur, het seizoen waar het item bij hoort en de stijl van het item. Vervolgens kun je zelf aangeven welke stijl of genres je op dat moment als outfit wilt hebben.
